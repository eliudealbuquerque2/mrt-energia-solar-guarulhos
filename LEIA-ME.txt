PUBLICAÇÃO GRATUITA NO GITHUB PAGES
1. Acesse https://github.com/ e crie uma conta, se necessário.
2. Crie um repositório público chamado mrt-energia-solar-guarulhos.
3. Dentro do repositório, use Add file > Upload files.
4. Envie os dois arquivos: index.html e logo-mrt.jpg.
5. Abra Settings > Pages.
6. Em Build and deployment, escolha Deploy from a branch.
7. Selecione branch main e pasta /(root); clique Save.
8. Aguarde e abra o endereço mostrado na seção Pages.
9. Teste o site e os botões do WhatsApp no celular.

Tutorial oficial: https://docs.github.com/en/pages/quickstart
